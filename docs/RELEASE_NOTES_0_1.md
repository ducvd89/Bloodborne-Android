Android 0.1 for the **AYN Thor** (Snapdragon 8 Gen 2, Android 13).

The single APK includes the ARM64 bbport runtime, FEXCore, FEX, Debian Linux rootfs, Turnip Vulkan driver, FSR 3.1, and first-run game preparation. It uses the Bloodborne icon from the builder's own dump. **No game executable, PS4 modules, game assets, or saves are included.**

The left-side menu can show or hide a PlayStation-style touch controller with face buttons, D-pad, sticks, shoulders, triggers, touchpad, and Options. Users can drag each control in Edit mode and restore the original layout with Reset. Visibility and positions persist, and the controls map to the game's pad input.

Install the APK, grant storage access, and select your own extracted **CUSA03173 v1.09** folder containing `eboot.bin`. Allow about 1 GB free beyond the game dump for the runtime and generated image. FSR 4 is disabled on this device.

The game is running on the AYN Thor's Snapdragon 8 Gen 2 at a reported 20–35 FPS during gameplay. Performance varies by scene and settings; other Android devices are untested. See [installation details](https://github.com/ducvd89/Bloodborne-Android/blob/android-0.1/docs/ANDROID_RELEASE_0_1.md).
