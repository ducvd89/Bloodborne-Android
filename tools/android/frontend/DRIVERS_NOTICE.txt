

================================================================================
GPU drivers bundled in the app (assets/drivers/)
================================================================================

The app carries these Vulkan drivers as the zips they were published in, byte for
byte (their sha256 is checked when the app is built: tools/android/fetch_bundled_drivers.sh):

  Adreno           Turnip_Gen8_V37.zip, for 6xx/7xx and 8xx alike
                   "Turnip for a8xx" (Mesa Turnip, also runs Adreno 6xx/7xx) built by StevenMXZ,
                   https://github.com/StevenMXZ/Adreno-Tools-Drivers, tag v37 (the repository
                   with the build scripts is licensed GPL-3.0; the text is below). Mesa Turnip
                   itself: MIT License. Source: that repository and tag, and Mesa
                   (https://gitlab.freedesktop.org/mesa/mesa). The zip is mirrored unchanged on this
                   project's release turnip-android-gen8-26.3.0-9c7e022
                   (https://github.com/ducvd89/Bloodborne-Android).
  Mali             PanVK-android-v3.2-universal-2a9358a.zip
                   Mesa PanVK for Mali (mali_kbase) from
                   https://github.com/JICA98/panvk-kbase-android, branch bachata/v3-upstream-beta13,
                   commit 2a9358a000fd691dac36d04c170fa3bd4101ff06, built by this project
                   (the zip's patches are on the release panvk-android-v3.2-2a9358a). Mesa: MIT
                   License. The zip contains its own LICENSE-mesa.rst, NOTICE.md and LICENSES/
                   (MIT, GPL-2.0 with the Linux syscall note, bcn_layer MIT).

The Mesa license text follows (LICENSE-mesa.txt of this project's Turnip 26.3.0 zip, verbatim), then the
GNU General Public License version 3 (https://www.gnu.org/licenses/gpl-3.0.txt), which covers
StevenMXZ's build repository.
