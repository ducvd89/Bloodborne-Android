fexdroid: https://github.com/cobrabm12/fexdroid (MIT License, below). The app's
Java package name comes from it; the display and input bridge libraries of earlier
releases (libfxdisplay, libfxio) are no longer included.

GPU drivers: the app carries three, unchanged, as assets/drivers/*.zip, and installs
the one for the phone's GPU when "Automatic" is the GPU driver setting; the notices for
them are at the end of this file (GPU drivers bundled in the app). Other Turnip for
Android builds the player installs or downloads from this project's GitHub releases are
Mesa (MIT, https://gitlab.freedesktop.org/mesa/mesa; the Adreno 8xx variant from
https://github.com/whitebelyash/mesa-unified, turnip/gen8, MIT), with this
project's patches (tools/android/mesa-patches in the source).

Lossless Scaling frame generation, Bloodframe (bbport/bionic/lib/libbloodframe.so):
based on lsfg-vk 1.0 by PancakeTAS via GameNative's Android fork of it; the framegen
backend and Lossless.dll shader extraction of that fork,
https://github.com/Ragnarok93/lsfg-vk-android (branch release, commit
0802cd33319c101e4c41f6828153d3331d8a3258; lsfg-vk by PancakeTAS), MIT License,
Copyright (c) 2025 lsfg-vk (bbport/licenses/bloodframe-lsfg-vk.LICENSE.md), with this
port's changes (tools/android/bloodframe-patches, tools/android/lsfg). It includes dxbc from DXVK
(zlib/libpng license; Copyright (c) 2017 Philip Rebohle, 2019 Joshua Ashton, 2019
Robin Kertels, 2023 Jeffrey Ellison), pe-parse (MIT, Copyright (c) 2013 Andrew Ruef)
and volk (MIT, Copyright (c) 2018-2025 Arseny Kapoulkine); the licenses are in
bbport/licenses/. Lossless Scaling and its Lossless.dll are not included: the app
downloads the player's own copy from Steam, or the player copies it.

Online play (bbport/bionic/lib/libbbnet20.so): the network, NP and shadNet code of
shadPS4 v0.20.0 (GPL-2.0-or-later, https://github.com/shadps4-emu/shadPS4) as ported by
bloodborne_pc 0.6 (GPL-2.0-or-later, https://github.com/deadinside28/bloodborne_pc),
BBSC seamless co-op (GPL-2.0-or-later, https://github.com/CLSAMG22/BBSC) and The
Hunter's Dream backend adapted from droogie/bbhost (GPL-3.0-or-later,
https://github.com/droogie/bbhost), so the module as a whole is GPL-3.0-or-later, with
this port's changes (gpu/bbnet20/android-changes.diff in the source). It links OpenSSL
3.5 (Apache-2.0), Protocol Buffers 3.21 (BSD-3-Clause), miniupnpc (BSD-3-Clause),
nlohmann/json (MIT) and cpp-httplib (MIT); their licenses are in bbport/licenses/. The
CA certificates (bbport/bionic/share/cacert.pem) are Mozilla's bundle as published by
curl.se (MPL-2.0; bbport/licenses/cacert-source.txt).

Steam sign-in (downloads Lossless.dll from the player's own Lossless Scaling):
JavaSteam 1.8.0 (MIT, https://github.com/Longi94/JavaSteam), with Kotlin and
kotlinx.coroutines/io/serialization (Apache-2.0, JetBrains), Ktor (Apache-2.0,
